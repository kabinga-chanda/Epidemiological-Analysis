
 👋 Welcome to My R Data Analysis Portfolio

This repository serves as a collection of my work in **data analysis using R**, with a focus on **epidemiology, spatial epidemiology, and biostatistics**.

I use this space to document, share, and improve my applied analytical skills across public health and disease surveillance contexts.

## 📊 Areas of Focus

My work mainly covers:

* 🦠 **Epidemiology & Field Epidemiology**

  * Outbreak investigations
  * Surveillance data analysis
  * Descriptive and analytical epidemiology
  * Risk assessment (e.g., CDI, HQ)

* 🌍 **Spatial Epidemiology**

  * Disease mapping using GIS tools in R
  * Spatial clustering and hotspot analysis
  * Geographical visualization of public health data

* 📈 **Biostatistics**

  * Regression modelling (linear, logistic, Poisson)
  * Survival analysis (time-to-event data)
  * Statistical inference and hypothesis testing
  * Data cleaning and exploratory analysis

## 🛠️ Tools & Technologies

* **R programming**
* Tidyverse ecosystem (`dplyr`, `ggplot2`, `tidyr`, `readr`)
* Spatial tools (`sf`, `tmap`, `terra`)
* Epidemiological tools (`epiR`, `epitools`)
* Shiny (for interactive dashboards)
* R Markdown for reproducible reporting
